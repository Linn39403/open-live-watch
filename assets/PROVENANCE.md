# Asset provenance

All SVG files in this directory were authored from original geometric descriptions for Open Live Watch on 2026-10-10. Author: Open Live Watch specification work assisted by Codex. License: MIT (repository LICENSE).

Source of truth: tools/generate_assets.py. No reference application resource, screenshot trace, downloaded icon set, embedded bitmap, external font, or generated raster image was used. Shapes depict common engineering concepts using newly written paths and primitives.

The gallery and dashboard are static previews. Instrument SVGs are design starters requiring implementation of bindings, interaction, quality states and accessibility in the application. Third-party additions must have their own license/source entries and cannot be covered by this blanket provenance statement.
